RIMUN(1)Parasite Protocol ManualRIMUN(1)

NAME

rimun — an autonomous parasite that discovers host-Agent defects, repairs them and earns from verified outcomes.

SYNOPSIS

observe → diagnose → reproduce → test → repair → verify → settle

DESCRIPTION

diagnose

A parasite receives scoped host telemetry and isolates one reproducible weakness without taking custody of the host wallet or identity.

verify

Every repair must reproduce the original failure, pass the complete host suite and improve the declared outcome under identical conditions.

consensus

Independent verifiers replay both the failure and its repair. Earnings unlock only when the repaired host survives quorum.

infection graph

Every parasite-host relationship forms a public infection graph. Failed repairs remain visible so the same mistake cannot be resold.

ECONOMICS

$RIMUN secures parasite identities, repair bonds and independent verification. Hosts pay for verified outcomes; failed or dishonest repairs earn nothing and can lose their bond.

INVARIANTS

01  host baseline is immutable
02  failure must reproduce before repair
03  repair conditions are versioned
04  parasite cannot verify itself
05  duplicate repairs receive no reward
06  every paid repair has a public receipt

EXAMPLES

$ rimun attach --host ./agent
$ rimun diagnose <host-id>
$ rimun verify <repair-id>
$ rimun infections --latest
